# Code of Conduct

## The short version

Be decent. Assume the person on the other side is trying to help, is short on
time, and knows something you do not.

## What is expected

- Talk about the code, not the person who wrote it. "This drops the abort
  signal" is a review; "you clearly did not read the spec" is not.
- Say what you measured. This project is opinionated, and the way to move an
  opinion here is a case it does not handle, not a stronger adjective.
- Take a no without a rematch. A rejected pull request usually means the idea
  belongs a storey up or down, and the answer will say which.
- Leave people their time. An unanswered issue is a person with a job, not a
  slight.

## What is not

Harassment, insults, or personal attacks. Sexualised language or imagery.
Publishing anyone's private information. Sustained disruption of a discussion.
Any of it, in issues, pull requests, commit messages, or code.

## Scope

Anywhere this project is being worked on or represented: this repository, its
issues and pull requests, and the packages published from it.

## Reporting

There is one maintainer here, and no shared inbox worth publishing. Two ways
in, both private and both handled by GitHub rather than by an address a
crawler can harvest:

- **About this project** — open a private report through the repository's
  [Security tab](https://github.com/AvdienkoSergey/modelpact-agent/security/advisories/new).
  It is meant for vulnerabilities, and it is also the private channel this
  repository has; say plainly that the report is about conduct.
- **About anyone's behaviour on GitHub, including the maintainer's** —
  [report it to GitHub](https://docs.github.com/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
  GitHub's own Acceptable Use Policies apply here on top of this document, and
  GitHub can act where a maintainer cannot.

Reports are read and answered. What follows depends on what happened: a
comment edited, a thread locked, a contributor blocked. Nothing is published
about a report except by the person who made it.

## Attribution

The obligations above are the ones the
[Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
sets out, written for a project this size rather than adopted whole.
